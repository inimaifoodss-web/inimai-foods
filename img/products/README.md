# Product photos

Put each product's **real photo** here, named by product id (p1.jpg … p35.jpg),
then set `img:"img/products/p1.jpg"` for that product in `index.html`.

Rules from the owner: only real photos of Inimai Foods products.
No cartoon/drawn pictures, no stock photos, no watermarked images.
Square-ish, about 800 px wide, JPG under 150 KB.
